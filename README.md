# Sanghoon Ji — academic homepage

Source of **<https://jasonjish.github.io>**.

I am a geographer working with GIS, spatial accessibility, human mobility, and
remote sensing / 3D reconstruction, currently a research assistant at George Mason
University Korea (M.S. Geography, Kyung Hee University). Publications, projects,
talks and my CV are on the site itself — this repository only holds the files
that build it.

## How it is built

A single page made with plain [Jekyll](https://jekyllrb.com/) — no theme, no plugins.
All content lives in the front matter of `index.html`; the layout, styles and
scripts are in `_layouts/`, `_includes/` and `assets/`. Pushing to `main` builds
and deploys the site through GitHub Actions.
