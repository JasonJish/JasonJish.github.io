{%- comment -%} The sideways strip of pictures and short clips inside one entry's panel. It shows exactly what index.html lists under that entry's `figures:`, in that order. items – the entry's `figures:` list; each item is `file:` + optional `caption:` (or just a file name) dir – the entry's archive folder, e.g. /assets/journal/img/J7/ title – the entry's title, used as alt text for a picture without a caption code – the entry's code (J7, P11 …) A picture is drawn from assets/auto/img//.jpg when that fast copy exists (made by _tools\auto.ps1) and from the original otherwise. A clip (.mp4, .webm) plays, silent and looping, from assets/auto/img//.mp4 when that light copy exists, with .jpg as the still shown until it starts. A click always opens the original. A listed file that is not in the folder is left out, and named in the box the local preview shows. {%- endcomment -%}
